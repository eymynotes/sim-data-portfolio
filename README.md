# sim-data-portfolio
usd-practice
Day 2: Hand-written USD. Wrote shelf.usda, ground.usda, and scene.usda by hand to learn stages, prims, attributes, one sublayer, and one reference. Verified with check_scene.py and viewed in Houdini.

Day 3: pxr Python API. build_scene.py creates a scene by script (a ground and 3 shelves in a loop) and prints the prim tree. This is the same structure as Day 2, now generated by code.

Day 4: Composition arcs. Built a scene where sublayer, reference, payload, inherits, and specializes compete. Predicted the winners using LIVRPS (Local, Inherits, VariantSets, References, Payloads, Specializes), then checked with check_arcs.py.

Day 5: Variants, materials, validator v0. build_asset.py makes a shelf with 3 color variants, each binding a different material. validate_asset.py checks defaultPrim, metersPerUnit, upAxis, and naming, and prints PASS or FAIL.
